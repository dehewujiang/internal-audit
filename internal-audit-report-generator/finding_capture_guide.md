# Finding 录入增强指南

> 配合 internal-audit-report-generator Skill 使用
>
> ⚠️ **职责边界**：逐项记录 finding 请优先使用 `audit-execution-assistant`（触发词："执行审计过程中记录异常"）。
> 本指南作为**补充录入方式**，适用于：①审计完成后补录历史发现 ②从外部来源获取的发现 ③快速批量录入

---

## 增强录入模式（推荐）

### 交互流程

```
用户：记录一个废料处置的审计发现

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📋 审计发现录入表单
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

请按 "字段=值" 回复，或点击保存继续

| 🔴 必填字段 | 当前值 | 状态 |
|------------|--------|------|
| 主题 | _待填写_ | ⏳ 待填 |
| 标题 | _一句话描述问题_ | ⏳ 待填 |

| 📝 核心字段 | 当前值 | 状态 |
|------------|--------|------|
| 风险级别 | □高 □中 □低 | ⏳ 待选 |
| 详细描述 | _问题具体表现_ | ⏳ 待填 |
| 审计依据 | _制度条款引用_ | ⏳ 待填 |
| 实际状况 | _发现的事实_ | ⏳ 待填 |

| 责任人 | _部门+姓名_ | ⏳ 待填 |
| 期限 | _YYYY-MM-DD_ | ⏳ 待填 |

输入格式："主题=废料处置" / "风险级别=高" / "责任人=采购部张三"
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 输入模式

### 模式1：逐字段模式
```
用户回复格式：字段名=值

Claude响应：
✅ [主题] 已更新为：废料处置

[显示最新表单状态]
```

### 模式2：批量模式
```
用户：
主题=废料处置
风险级别=高
标题=废料出售价格低于市场价15%

Claude响应：
✅ 3个字段已更新
   → 主题: 废料处置
   → 风险级别: 高
   → 标题: 废料出售价格低于市场价15%

[继续填写剩余字段...]
```

### 模式3：自然语言提取
```
用户：我在废料审计中发现，3月份出售废料的价格比上海有色金属网报价低了15%，没有合理解释，怀疑与回收商有勾结。建议重新比价，责任人是采购部李四。

Claude自动提取：
✅ 从描述中识别到：
   → 主题: 废料处置审计
   → 风险级别: 高 (存在舞弊嫌疑)
   → 标题: 废料出售价格低于市场价15%
   → 详细描述: 3月份废料出售价格与市场价存在15%差异
   → 实际状况: 价格比上海有色金属网低15%
   → 根本原因: 涉嫌与回收商勾结
   → 整改建议: 重新比价
   → 责任人: 采购部李四

[请确认或补充信息]
```

## 校验规则

| 字段 | 校验 | 失败提示 |
|------|------|----------|
| 主题 | 不能为空 | 🔴 "请填写审计主题（如'废料处置'）" |
| 标题 | 不能为空 | 🔴 "请用一句话描述问题" |
| 标题 | 长度<100字符 | 🟡 "标题过长，建议精简" |
| 风险级别 | ∈ {高,中,低} | 🔴 "请选择高/中/低之一" |
| 责任人 | 格式"部门+姓名" | 🟡 "建议格式：部门+姓名，如'采购部张三'" |
| 期限 | YYYY-MM-DD格式 | 🟡 "日期格式错误，请用 YYYY-MM-DD" |
| 整改建议 | 可执行性判断 | 🟡 "建议应具体可执行，如'重新比价'" |

## 上下文辅助

Claude 会自动读取 about-me.md，提供智能填充建议：

**示例1：**
- 检测到文献使用 "用友U8" → 自动建议 "从U8导出数据" 而非 "从ERP导出"

**示例2：**
- 检测到4地生产 → 风险级别建议：协同风险需特别关注

## 快捷命令

| 命令 | 作用 |
|------|------|
| `跳过` | 跳过可选字段，进入下一步 |
| `完成` | 确认保存当前finding |
