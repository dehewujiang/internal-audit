## HR系统架构说明

```
┌─────────────────────────────────────────────────────┐
│                    HR 系统架构                        │
├───────────┬───────────┬───────────┬─────────────────┤
│  考勤数据  │  薪酬计算  │  HR审批   │  财务/物流/成本  │
│ 独立打卡机  │  Excel    │  泛微OA   │  SAP ERP        │
│ (非SAP)   │ (手工)    │          │  (无HR模块)      │
└───────────┴───────────┴───────────┴─────────────────┘
```

**关键系统事实（审计取证基础）**：
- 考勤：独立打卡考勤系统（非SAP HR模块），打卡记录可能导出为Excel/CSV
- 薪酬：Excel手工计算（非系统自动），公式+手工录入，无SAP HCM
- 审批：泛微OA承载所有HR审批流程（加班申请/请假/出差/薪资审批等）
- SAP：仅负责财务记账、物流管理、成本核算，不管理任何HR主数据
- 薪酬计算流程：考勤机导出数据 → 各部门提交津贴明细 → Excel汇总计算 → OA薪资审批 → 银行代发
- 无HR系统间自动对接：考勤→薪酬为手工传递，薪酬→财务为手工凭证录入
