# 控制点分类体系

## 概述

本文档定义了企业内部制度中常见的控制点分类体系，用于document-organizer在分析制度文档时标准化控制点的提取和分类。

## 控制点分类框架

### 一级分类：控制类型

| 代码 | 类型 | 定义 | 典型关键词 |
|------|------|------|-----------|
| AP | 审批权限控制 (Approval) | 规定某事项需经特定人员/层级审批 | 审批、批准、签字、审核、核准 |
| SS | 职责分离控制 (Segregation) | 规定不相容职责需由不同人员/部门执行 | 职责分离、不相容、分别、不同人员、独立 |
| RC | 定期检查控制 (Regular Check) | 规定某事项需按固定频率进行检查/复核 | 定期、每月、每季度、每年、按时、复核 |
| DR | 文档记录控制 (Documentation) | 规定某事项需形成书面记录并保存 | 记录、登记、台账、留存、归档、保存 |

### 二级分类：业务领域

| 代码 | 领域 | 说明 |
|------|------|------|
| PUR | 采购管理 | 供应商管理、采购申请、订单、验收、付款 |
| INV | 存货管理 | 入库、出库、保管、盘点、呆滞料 |
| PROD | 生产管理 | 生产计划、工艺、质量、设备 |
| SALES | 销售管理 | 订单、发货、收款、退货 |
| FA | 固定资产 | 购置、使用、处置、盘点 |
| HR | 人力资源 | 招聘、薪酬、考勤、绩效 |
| FIN | 财务管理 | 资金、费用、报销、预算 |
| IT | 信息系统 | 权限、安全、备份、变更 |
| SCRAP | 废料管理 | 废料产生、收集、过磅、出售、收款 |

### 三级分类：控制设计有效性评估标准

| 评级 | 标准 | 说明 |
|------|------|------|
| 有效 | 控制措施具体、可执行、可验证 | 有明确的审批层级、金额阈值、检查频率 |
| 部分有效 | 控制措施存在但不够具体 | 有审批要求但无金额分级，有检查要求但无频率 |
| 无效 | 控制措施过于笼统或无法验证 | "适当审批"、"定期检查"等模糊表述 |

## 控制点提取规则

### 规则1：每个控制点必须包含5要素

1. **控制类型**：AP/SS/RC/DR
2. **控制对象**：什么业务活动
3. **控制要求**：具体做什么
4. **控制主体**：谁来做
5. **控制频率**：多久做一次（如适用）

### 规则2：baseline_audit_program必须包含5要素

1. **objective**：测试目标
2. **sample_criteria**：样本选择标准
3. **evidence_source**：证据来源
4. **test_steps**：测试步骤（至少3步）
5. **pass_criteria**：通过/不通过标准

### 规则3：控制点ID编码规则

格式：`{业务领域代码}-{控制类型代码}-{序号}`

示例：
- `PUR-AP-001`：采购管理-审批权限控制-第1个
- `INV-SS-002`：存货管理-职责分离控制-第2个
- `SCRAP-RC-001`：废料管理-定期检查控制-第1个

## 汽车零部件行业专项控制点

### 紧固件行业特有风险控制

| 控制领域 | 关注点 | 典型控制要求 |
|---------|--------|-------------|
| 原材料检验 | 钢材材质证明 | 每批次钢材需附材质证明书，质检部核对 |
| 热处理 | 温度/时间记录 | 热处理工艺参数自动记录，偏差超±5℃报警 |
| 成品检验 | 强度等级测试 | 每批次抽样进行拉力/硬度测试 |
| 模具管理 | 模具寿命追踪 | 模具使用次数记录，达寿命自动锁定 |

### 冲焊件行业特有风险控制

| 控制领域 | 关注点 | 典型控制要求 |
|---------|--------|-------------|
| 冲压模具 | 模具维护 | 定期维护保养记录，损坏模具隔离存放 |
| 焊接质量 | 焊缝强度 | 焊接参数监控，首件检验，巡检 |
| 边角料 | 废料管理 | 边角料分类收集，过磅记录，出售审批 |
| 客户定制 | 专用件管理 | 客户专用模具/工装标识，防止混用 |
