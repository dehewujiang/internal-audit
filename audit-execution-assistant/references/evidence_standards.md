# 证据标准与要求

## 证据等级

| 等级 | 类型 | 可靠性 | 示例 |
|------|------|--------|------|
| A | 系统直接导出 | 高 | SAP导出的采购订单清单（含系统时间戳） |
| B | 系统截图 | 中高 | 系统审批流程截图 |
| C | 手工记录 | 中 | 手工填写的盘点表 |
| D | 口头描述 | 低 | 员工口述流程 |
| E | 第三方证据 | 高 | 供应商对账单、银行流水 |

## 证据完整性要求

### 控制测试（测试控制是否被执行）

| 要素 | 要求 |
|------|------|
| 样本量 | ≥25个（一般控制）或≥60个（关键控制） |
| 时间覆盖 | 覆盖整个审计期间 |
| 证据类型 | A级或B级 |
| 异常处理 | 发现异常需扩大样本量 |

### 实质性测试（测试是否存在异常）

| 要素 | 要求 |
|------|------|
| 样本量 | 全量分析或统计抽样 |
| 时间覆盖 | 覆盖整个审计期间 |
| 证据类型 | A级优先，B级可接受 |
| 异常处理 | 发现异常需穿透核查 |

## 证据链完整性

完整的证据链应包含：
1. **来源**：证据从哪个系统/文件获取
2. **获取时间**：何时获取
3. **获取方式**：如何获取（导出/截图/访谈）
4. **获取人**：谁获取的
5. **存储位置**：存放在哪里
6. **完整性校验**：哈希值或其他方式
