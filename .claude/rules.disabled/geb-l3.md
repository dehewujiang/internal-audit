# L3 文件头部契约（带豁免机制）

## 触发与豁免条件

- **强制触发**：文件超过 50 行，或属于核心业务逻辑（如 `services/`, `api/` 目录）。
- **豁免条件**：文件 50 行以下的小脚本、纯配置文件、仅包含样式的组件。豁免文件无需写 L3 头部，避免过度形式化。

## 头部模板（强制触发时使用）

```
/**
 * [INPUT]: 依赖 {模块/文件} 的 {具体能力}
 * [OUTPUT]: 对外提供 {导出的函数/组件/类型/常量}
 * [POS]: {所属模块} 的 {角色定位}, {与兄弟文件的关系}
 * [PROTOCOL]: 变更时更新此头部, 然后检查同级 CLAUDE.md
 */
```
## 同步规则

- 文件内容发生架构级变更（接口增删/职责转移） → 先更新此头部 → 再检查同级 CLAUDE.md。
- 日常微调（改参数值、修 Bug、优化逻辑）无需更新头部。
- 头部与代码严重不一致是 YELLOW 警告，任务结束前必须清偿。
