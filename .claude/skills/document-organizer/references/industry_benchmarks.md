# 行业制度基准

## 概述

本文档定义了汽车零部件（紧固件/冲焊件）企业各业务领域应建立的制度基准，以**控制维度**为最小单元。用于 document-organizer 两遍分析法中判断"某领域是否应覆盖某个控制维度"，作为提取完整性的对照标尺。

## 制度基准框架

### P0（必须建立）— 控制维度清单

#### 存货管理（P0）

| 控制维度 | 控制类型 | 应覆盖的关键点 |
|---------|---------|--------------|
| 入库管理 | 审批(AP) + 记录(DR) | 入库单审批层级、质检前置、入库台账 |
| 出库管理 | 审批(AP) + 记录(DR) | 出库申请-审批-发货三步、出库单与订单匹配 |
| 盘点管理 | 定期检查(RC) + 职责分离(SS) | 盘点频率（月/季）、监盘人独立于仓管、差异分级处理 |
| 呆滞料管理 | 定期检查(RC) | 呆滞定义标准（库龄阈值）、定期清理机制、责任归属 |
| 保管管理 | 职责分离(SS) + 记录(DR) | 仓管与记账分离、出入库台账、温湿度/防锈环境控制 |

| 控制维度 | 控制类型 | 应覆盖的关键点 |

| 供应商准入 | 审批(AP) | 新供应商评估标准、准入审批层级、样品验证 |
| 采购审批 | 审批(AP) | 金额分级审批（示例：≤5万/5-50万/>50万）、紧急采购例外流程 |
| 价格管理 | 审批(AP) + 记录(DR) | 比价/议价留痕、价格审批独立于采购员 |
| 采购验收 | 职责分离(SS) + 记录(DR) | 采购人与验收人分离、验收标准量化、不合格品处理 |
| 采购付款 | 审批(AP) + 职责分离(SS) | 付款审批与采购审批分离、发票-订单-验收单三单匹配 |

## 各业务领域控制维度清单

### 控制类型缩写说明

| 缩写 | 含义 | 说明 |
|------|------|------|
| AP | Approval（审批授权） | 关键业务需经适当层级审批 |
| SS | Segregation of Duties（职责分离） | 不相容岗位由不同人员担任 |
| RC | Regular Check（定期检查） | 定期复核、盘点、分析、审计 |
| DR | Document & Record（文档记录） | 业务过程留痕、台账、档案管理 |

## 制度缺失判定指南

### 判定流程

```
1. 对照"控制维度清单"，列出该业务领域应覆盖的所有控制维度
    ↓
2. 在所有制度文件中检查是否有对应维度的规定
    ↓ 无匹配
3. 检查是否有跨文件引用（如"详见XX制度第X条"）
    ↓ 无
4. 判定为"制度缺失"，verification_status="已确认"
```

### 特殊情况处理

| 情况 | 处理方式 |
|------|---------|
| 制度名称不同但覆盖相同领域 | 视为已覆盖（如"仓储管理制度"覆盖存货管理） |
| 制度仅提及但未详细规定 | 标记为"制度不可操作"，非"缺失" |
| 制度存在但严重过时 | 标记为"制度过时"，非"缺失" |
| 企业规模小，不需要该制度 | 标记为"待确认"，由用户判断 |

## 制度与现实差距扫描

基于行业经验，以下领域是中小企业常见的"制度有但实际未执行"的高发区：

| 领域 | 制度通常规定 | 实际常见做法 | 差距风险 |
|------|-------------|-------------|---------|
| 盘点 | 每月/每季度盘点 | 年末盘点或根本不盘点 | 账实不符未发现 |
| 供应商评估 | 定期评估 | 不评估或走过场 | 供应商质量/价格失控 |
| 废料管理 | 过磅+审批 | 口头通知+手工记录 | 废料收入被侵占 |
| 模具管理 | 台账+寿命追踪 | 无台账或台账不完整 | 模具流失/重复采购 |
| 职责分离 | 明确规定 | 人员不足时一人多岗 | 舞弊风险增加 |

## 行业基准版本管理

本文档是 document-organizer 提取完整性的对照基准。每次以下事件发生后应审查本基准是否需要更新：
