# 边界情况处理

| 情况 | 处理方式 |
|------|---------|
| **制度缺失** | 标记为"制度缺失"，verification_status="待确认"，建议建立相关制度 |
| **制度过时** | 标记为"制度过时"，建议更新 |
| **制度冲突** | 标记为"制度冲突"，列出冲突条款 |
| **制度不可操作** | 标记为"不可操作"，说明原因 |
| **模糊条款** | 标注为"需进一步明确" |
| **矛盾描述** | 标注并指出矛盾点 |
| **文件无法读取** | 标记"无法分析"，跳过并记录原因 |
| **单文件分析** | 警告用户"仅分析单份文件可能误判缺失"，所有control_gaps标记verification_status="待确认" |
| **制度文件超过100页** | 分章节分析，先提取目录建立索引，再逐章分析 |
