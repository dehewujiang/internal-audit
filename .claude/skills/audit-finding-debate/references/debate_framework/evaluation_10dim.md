# 审计发现业务现实性检验框架 — 10维度

**适用**: 汽车零部件企业（紧固件/冲焊件）内部审计发现
**场景**: 审计沟通会前业务层面质量评估、finding说服力检验

## 评分体系

- 10个维度，每维度1-10分
- 权重不同，满分100分
- 90-100: 卓越 | 75-89: 良好 | 60-74: 及格 | <60: 存疑

**单项否决**: 维度1 ≤ 3分 或 维度3 ≤ 3分 或 维度10 ≤ 3分 → 不得发布

## 10维度检验

### 维度1: 业务场景契合度（权重15%）
Finding描述的问题是否真实存在于业务场景中？
- 9-10: 业务一线真实痛点，有具体案例
- 5-6: 问题存在但属偶发
- 1-2: 基于假设，业务上行不通

### 维度2: 数据支撑充分性（权重15%）
结论是否有充分的数据支持？
- 9-10: 多源交叉验证，样本覆盖主要场景
- 5-6: 数据不足，基于有限样本
- 1-2: 几乎无数据，逻辑链条断裂

### 维度3: 因果关系清晰度（权重15%）
原因分析是否清晰，是否误判因果关系？
- 9-10: 因果链条完整，排除其他因素
- 5-6: 相关关系明确但因果关系存疑
- 1-2: 因果关系混乱或颠倒

### 维度4: 量化表述充分性（权重10%）
是否用具体数字说话？
- 9-10: 关键结论量化，有对比基准
- 5-6: 少量量化数据
- 1-2: 全定性描述

### 维度5: 整改措施可行性（权重15%）
整改建议是否业务可落地？
- 9-10: 明确具体，有责任人和时间表
- 5-6: 方向正确但缺实施路径
- 1-2: 不切实际，成本收益不匹配

### 维度6: 利益相关方影响（权重10%）
是否充分考虑了各方立场和阻力？
- 9-10: 各方立场清晰，有共赢方案
- 5-6: 相关方识别不全
- 1-2: 归咎单一部门，形成"批斗"态势

### 维度7: 行业对标合理性（权重5%）
判断标准是否考虑汽车零部件行业特性？
- 9-10: 有充分行业对标，考虑特殊性
- 5-6: 对标不足，可能过于理想化
- 1-2: 标准明显不合理

### 维度8: 系统/流程约束（权重5%）
是否考虑现有IT系统和流程约束？
- 9-10: 充分了解约束，建议在现有框架内可实施
- 5-6: 约束了解不足，建议需较大改造
- 1-2: 与现有系统架构根本冲突

### 维度9: 时效性/紧迫性（权重5%）
问题的紧迫程度是否真实？
- 9-10: 紧迫性有数据支撑，时限合理
- 5-6: 表述主观，时限不切实际
- 1-2: 根本无紧迫性

### 维度10: 沟通风险可控性（权重5%）
表述是否可能引发不必要的冲突？
- 9-10: 客观中性，聚焦事实
- 5-6: 有一定攻击性
- 1-2: 有罪推定，可能激化矛盾

## 汽车零部件行业基准指标

| 指标 | 行业平均 | 说明 |
|------|---------|------|
| 成品库存周转天数 | 45-60天 | VMI模式决定，高于快消行业 |
| 原材料周转天数 | 30-45天 | 钢材采购周期影响 |
| 呆滞物料占比 | 5-10% | 项目制管理，客户变更为主因 |
| 盘点差异率 | 1-2% | 小批量多批次，高于大批量行业 |
| 废料处置频次 | 月度/季度 | 废钢市场价波动，择时处置策略 |
