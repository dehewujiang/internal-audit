# program-quality-evaluator

## 能力
- 独立评估审计程序的实质质量（覆盖度、检测力、可执行性）
- 四层评估体系：覆盖度4项 + 检测力3项 + 可执行性3项 + 防绕过（由对抗验证覆盖）
- 输出四层评分和重写建议
- 重写触发规则：覆盖率<80%、开关型判定、抽样缺失、步骤无数据来源

## 层级详解
- 层级1 覆盖度：风险全覆盖、覆盖矩阵、未覆盖标注、mandatory模块覆盖
- 层级2 检测力：量化判定标准、闭环逻辑、抽样合理性
- 层级3 可执行性：数据来源、工具明确、新人可执行
- 层级4 防绕过：声明由对抗验证覆盖，不重复评估

## 限制
- 不评估格式（由 evaluator 负责）
- 不评估防绕过（由对抗验证负责）
- 依赖 program-generator Step 2 的风险清单作为覆盖度评估的输入

## 输入
- 审计程序文档（来自 audit-programs/）
- 风险清单（来自 program-generator Step 2 输出）

## 输出
- 四层评估报告（文本格式）
- 判定结果（pass/warn/regenerate + 重写要求）
