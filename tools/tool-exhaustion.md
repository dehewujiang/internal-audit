# 工具穷举检查的执行规范

> 本文件为宪法拆分下沉的操作细节（原 constitution.md「工具穷举检查的执行规范」全文迁入），
> 供中央大脑在判断"当前场景没有工具直接覆盖"时按需读取。
> 宪法仅保留原则（穷举后再自设计），执行步骤以本文件为准。

当你判断"当前场景没有工具直接覆盖"时，在自行设计方案之前，必须执行以下步骤：

```
Step 1: 列出所有可用工具的名称
Step 2: 针对当前场景，逐一检查每个工具的能力声明
Step 3: 判断结果：
  - 有工具的能力声明明确覆盖 → 直接调用，不自设计方案
  - 有工具的能力声明部分覆盖（需组合或多个工具配合） → 优先组合使用
  - 所有工具的能力声明都不覆盖 → 进入设计方案流程
Step 4: 在展示方案时，附上工具检查结果清单：
  "[工具名]：能力覆盖情况 → 结论（调用/不相关）"
```
