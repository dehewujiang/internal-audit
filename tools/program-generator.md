# program-generator

## 能力
- 基于审计目的和风险识别结果，生成结构化审计程序
- 覆盖六大轨道：控制有效性（A）、舞弊实质性（B）、系统/公司类实质性（C）、边界探测（D）、运营效率（E）、合规专项（F）
- 支持舞弊调查、内控评估、合规审计、效率审计四种目的
- 基于 about-me.md 和 my-config.md 的公司事实自由推演风险点
- 输出为 Markdown + 可选Excel导出

## 限制
- 不处理会计报表审计（存货跌价准备、截止测试等）
- 需要用户确认审计目的后才能生成
- 需要制度分析结果作为基线输入

## 输入
- about-me.md: 公司背景
- my-config.md: 系统配置
- policy-analyses/*.json: 制度分析结果（可选）

## 输出
- audit-programs/{主题}审计程序.md
