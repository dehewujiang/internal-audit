## 章节激活规则速查表

| 审计目的 | 激活轨道 | 跳过章节 |
|---------|---------|---------|
| 舞弊调查 | A + B + C + D | 六、七 |
| 内控效果评估 | A（深化）+ B + C + D | 六、七 |
| 合规性审计 | A + F + C + D | 四、六 |
| 运营效率审计 | A + E + C + D | 四、七 |
| 舞弊+内控+合规 | A + B + C + D + F | 六 |
| 全面审计 | A + B + C + D + E + F | 无 |
