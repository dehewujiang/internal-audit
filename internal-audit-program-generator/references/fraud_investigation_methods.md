# 舞弊调查方法与技巧

---

## 一、舞弊调查工作流

```
举报受理 → 信息甄别 → 项目立项 → 暗中调查 → 固定证据 → 谈话突破 → 后续处理
    ↑         ↓           ↓         ↓         ↓         ↓         ↓
  线人机制  可信度评估   定基调    保密原则    证据链     软肋识别   整改/报案
```

---

## 二、舞弊线索来源

| 来源类型 | 具体渠道 | 注意事项 |
|---------|---------|---------|
| **实名举报** | 员工/供应商主动提供 | 核实举报人动机，排除打击报复 |
| **匿名举报** | 邮件/电话/系统举报 | 需鉴别真伪，必要时反向追踪举报人 |
| **日常审计** | 常规审计中发现异常 | 不能仅停留于流程合规，要分析行为动机 |
| **关联案件** | 其他案件当事人供述 | 通常"拔出萝卜带出泥" |
| **技术监控** | 深信服等操作监控系统 | 调阅敏感操作日志 |

### 线人培养机制

**选择标准**：
- 职能部门人员（财务、人事、行政、保安）
- 同期入职员工、有共同爱好者
- 工作中"聊得来"的同事

**信息加工**：
- 培训舞弊识别要点（时间、人员、单据、异常行为）
- 线索需验证，避免"猪队友"误判（如退货返修被误认为重复发货）

## 三、信息甄别与立项

### 无效举报识别

| 类型 | 特征 | 案例 |
|-----|------|------|
| 政策理解不足 | 将正常福利差异误认为违规 | 劳务派遣工投诉正式工专属福利 |
| 个人情绪 | 攀比心理、嫉妒 | 同事技能等级高薪酬高被举报"送礼" |
| 打击报复 | 敏感时期（年底考核）举报 | 无实据的虚假举报 |
| 外界乌龙 | 联系方式留错 | 网贷逾期电话打到审计部 |

### 有效线索标准

必须明确：
1. **舞弊事实**：谁、何时、何地、何种舞弊、涉及金额
2. **信息来源**：如何获悉、是否受利益方影响
3. **举证能力**：是否有可获取的内部记录（控制痕迹）
4. **举报动机**：期望结果（送监狱/开除/赔偿/内部整改）

### 立项前确认

- [ ] 是否损害公司利益（非门卫收豆浆等琐事）
- [ ] 舞弊事实是否清晰（非"XXX收取贿赂"等模糊表述）
- [ ] 管理层态度与期望（送进去/开除/追回即可）
- [ ] 是否存在"背黑锅"风险（经办人替主谋担责）

## 四、暗中调查阶段

### 核心原则：保密第一

- **人员保密**：少数人知情，调查组成员严格限制
- **身份掩护**：以"定期审计"或"体系贯标"名义进场
- **打哈哈**：对方询问目的时含糊其辞
- **防止串供**：敏感问题面对面沟通，禁止邮件

### 外围调查要点

| 维度 | 调查内容 | 方法 |
|-----|---------|------|
| **社会关系** | 股权、房产、车、存款 | 企查查、委托调查事务所 |
| **价格信息** | 市场价、真实成本 | 仿真询价、行业人脉 |
| **业务痕迹** | 修改记录、邮件往来 | 系统日志、电子取证 |
| **供应商尽调** | 实际控制人、关联关系 | 工商信息、实地拜访 |

### 证据固定方法

1. **电子证据**
   - 电脑镜像
   - 邮件恢复
   - 微信/聊天记录
   - 文件属性（创建/修改时间）

2. **物理证据**
   - 仓库盘点照片
   - 设备拆解对比
   - 过磅监控录像

3. **第三方证据**
   - 银行流水（合作银行）
   - 船公司报价单
   - 厂家授权确认

4. **书面证据**
   - 微信聊天记录（截图+录屏）
   - 通话录音
   - 酒店流水单

## 五、谈话突破技巧

### "排山倒海"压力策略

**时机选择**：下午4-5点，对方急于下班时

**环境布置**：
- 单独房间、封闭空间
- 律师/法务陪同
- 证据文件摆满桌面

**话术模板**：
> "如昨日沟通，若您能配合我们对过往事项开展调查，并提供与我司员工(含离职人员)的所有经济往来记录及礼品赠送记录，我们能确保您与过往事项彻底切割不影响双方后续的合作，还望您慎重考虑。"

**回应判断**：
- "我在找" → 确认收钱
- "我需要确认" → 心虚犹豫
- "我没问题" → 需要加码压力

### 软肋识别与施压

| 对象类型 | 软肋 | 施压方式 |
|---------|------|---------|
| **供应商** | 经销商资质、企业声誉 | 威胁举报厂家、取消代理权 |
| **员工** | 职业前途、家庭关系 | 通知配偶/父母、报案后果 |
| **管理层** | 个人资产、社会地位 | 外部调查、媒体曝光风险 |

### 心理突破点

1. **沉默施压**：长时间沉默让对方主动交代
2. **文件重压**：当面出示转账记录、邮件等核心证据
3. **分而对之**：同时约谈相关人员，防止串供
4. **家庭压力**：通知家庭成员到场
5. **典型案例**：引用已处理的相似案件

### 突破原则

- **由小到大**：先突破经办人，再指向主谋
- **由低到高**：先基层员工，后中高层
- **由外到内**：先外围供应商，后内部人员
- **半真半假**：顺着已知消息聊，夹杂推测内容

## 六、证据链构建

### 完整证据链要素

```
主观故意 + 客观行为 + 损害金额 + 因果关系
    ↓         ↓         ↓         ↓
明知故犯   具体操作   计算依据   time/causal link
```

### 三流合一验证

| 类型 | 验证内容 |
|-----|---------|
| **财务流** | 银行流水、支付记录、发票 |
| **业务流** | 合同/订单、入库单、发货单 |
| **实物流** | 监控录像、现场盘点、物流信息 |

### 典型证据组合

**采购回扣案**：
- 仿真询价价格 vs 合同价（价差证明）
- 调价记录（滞后市场价）
- 优先付款记录
- 质量索赔让步记录
- 供应商/采购员转账记录

**废料舞弊案**：
- 过磅记录（同一车辆皮重波动）
- 监控录像（水箱排水/二次装料）
- 现场抓现行（扣车称重）
- 废料商/司磅员承认笔录

## 七、后续处理

### 报案标准

符合以下条件建议报案：
1. 侵占款项已挪用，无法赔偿公司损失
2. 性质恶劣、波及广，需要"杀鸡儆猴"
3. 事实清楚但拒绝配合

### 报案材料准备

**刑事控告书**：
1. **案情陈述**：主观故意 + 客观损害金额
2. **法律分析**：涉嫌罪名 + 立案标准条款

### 管理整改

1. **人员层面**：
   - 开除/劝退责任人
   - 更换管理团队（如需要）
   - 提高薪资水平降低舞弊动机

2. **制度层面**：
   - 岗位职责分离
   - 系统权限控制
   - 轮岗与监督机制

3. **文化层面**：
   - 反舞弊宣传
   - 警示教育
   - 廉洁协议签署

## 八、关键提醒

### 一次性原则

> "舞弊调查应该是'公司'的'一次性'调查，即一件舞弊案件：一次调查，一次查实，一次定性，一次处理。"

二次以上调查会给舞弊者充分的反应期，导致调查失败。

### 尊重命运

> "尊重他人命运，放下助人情节。"

某审计组出于人道考虑销毁录音，结果被反咬一口"关小黑屋、逼供诱供"。掌握证据前不要心软。

### 防止反咬

- 全程录音录像
- 书面确认签字
- 证据原件保留
- 调查报告不公开（除非授权）
