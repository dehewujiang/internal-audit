# 桌子格式（正式格子，v1.0）

一张桌子只记一件事，比如冲压车间废料多了。
旧房间一个没动，这叠纸是新加的。

## 格子

* 左边三格，固定不变：确定的毛病、怀疑偷骗（标红）、说不清的信号。
* 右边贴证据，每条必须写谁给的、啥时候给的，能对上证据柜里的槽位号就写上，对不上写文件名也行。
* 抽屉三张表：问话表、检查表、报告表。
* 打勾纸三句：证据够了吗、制度看全了吗、红格看了吗。

## 新旧对照

* 左边三格 ← 以前散在检查单、问题单里的怀疑，现在收拢到一处。
* 右边证据 ← 证据柜（_evidence_catalog.json）的槽位，槽位号、文件名、谁给的、哪天，原样抄过来。
* 下面来源 ← 以前 finding 里谁、什么时间、从哪来的那行字。
* 红格 ← 以前舞弊标记，现在单独一格标红。
* 抽屉 ← 以前三个房间吐的三张表格。

## 房间分工（一家管一处，只添不盖）
* 看制度 → 信号格（D观察，add-line）
* 问话 → 信号格（风险线索）+ 右边（证据/记录）
* 检查单 → 不用接：产出本来就是抽屉里的检查表，约定即接口
* 执行取证 → 第一格/红格/右边（import 单张，落定即上桌）
* 吵架 → 改字（set-slot，改前自动拍照）
* 报告 → 只读（Step 2b 跑 audit_table.py，不写）
